# 演示视频与关键帧

本目录保存积木入杯任务的演示视频与关键帧。ACT 展示夹爪在两块积木之间空抓、碰杯及杯子倒下的过程；π0.5 展示初始桌面、三种摆放姿态的抓取及最终入杯。

单张关键帧保留完整画面；`storyboard` 图片为裁剪并添加图注的展示拼图。

```text
demo/
├── README.md
├── act.mp4                  # ACT 失败演示
├── pi05.mp4                # π0.5 成功演示
├── all.mp4                  # 其他演示视频
└── keyframes/
    ├── act_01.jpg           # 两块积木之间空抓
    ├── act_02.jpg           # 接触杯子，杯子倾斜
    ├── act_03.jpg           # 杯子倒下
    ├── act_storyboard.jpg   # ACT 展示拼图
    ├── pi05_01.jpg          # 初始桌面状态
    ├── pi05_02.jpg          # 抓取倒放的红色积木
    ├── pi05_03.jpg          # 抓取侧放的蓝色积木
    ├── pi05_04.jpg          # 抓取正放的绿色积木
    ├── pi05_05.jpg          # 最后一块积木入杯
    └── pi05_storyboard.jpg  # π0.5 展示拼图
```
